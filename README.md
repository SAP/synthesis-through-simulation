# synthesis-through-simulation

## About this project

The system generates coherent enterprise database records by having a domain-agnostic LLM agent execute structured tasks against policy-enforcing mock environments. The core contribution is the Generalist Populator (GP), a three-phase agent (Explore → Plan → Execute) that learns an environment's entity graph and distribution priors from scratch, then populates the database with high-fidelity, constraint-valid records.
